# cli‑todo

A tiny command‑line todo list manager written in Python.

## Features
- Add a new task
- List all pending tasks
- Mark a task as completed
- Delete a task
- Persistent storage in `todos.json`

## Installation
```bash
# Clone the repo
git clone https://github.com/yourusername/cli-todo.git
cd cli-todo
# (Optional) create a virtualenv
python3 -m venv .venv
source .venv/bin/activate
# No external dependencies required
```
